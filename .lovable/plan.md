

# Chat Application UI Clone

## Overview
A pixel-perfect UI clone of a messaging application with a sidebar navigation, conversation list, and chat view — using mock/static data. We'll build the layout first, then refine with Figma code you paste.

## Theme & Styling
- Custom color palette: light green backgrounds (#F0FDF4), dark text (#1C1C1C), gray secondary (#8B8B8B), cream sidebar (#F3F3EE), green accents (#38C793, #1E9A80)
- Font style to be confirmed when you share from Figma
- Clean, rounded UI with subtle shadows

## Pages & Layout

### 1. Main Chat Layout
- **Left icon sidebar**: Home, Messages, Notes, Files, Media icons + user avatar at bottom
- **Conversation list panel**: "All Message" header, "New Message" button, search bar with filter, list of conversations with avatars, names, preview text, and timestamps
- **Chat area**: Active conversation with message header (name, online status, action icons), message bubbles, timestamps, and input bar

### 2. Key UI Components
- **Conversation list item**: Avatar, name, message preview, timestamp, read receipts
- **Message bubbles**: Left-aligned (received) in white/light, right-aligned (sent) in green (#1E9A80) with white text
- **Context menu**: Right-click on conversation → Mark as unread, Archive, Mute, Contact info, Export chat, Clear chat, Delete chat
- **Message input bar**: Text input, mic, emoji, attachment, and send button icons
- **Chat header**: User avatar, name, online status, search/call/video/more icons

### 3. Interactive Elements (static/mock)
- Clickable conversations that switch the chat view
- Context menu on right-click
- Hover states on sidebar icons and conversation items
- Active conversation highlighting

## Approach
1. Build the full layout from the screenshot with mock data
2. You'll paste Figma code for specific components and I'll integrate/refine them
3. Iterate until pixel-perfect
